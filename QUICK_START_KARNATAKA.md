# 🚀 Quick Start - Karnataka Business Ideas

## Start the Server

```bash
# Windows
launch.bat

# Linux/Mac
./launch.sh

# Or directly
python app_clean.py
```

## Access the Application

Open your browser: **http://localhost:5000**

## Try Karnataka Business Ideas

### Option 1: Click Sidebar Buttons
Look for the **"🏛️ Karnataka Business Ideas"** section in the sidebar and click:
- 🏙️ Bengaluru
- 🏰 Mysuru
- 🌊 Mangalore
- 🌾 Mandya
- ☕ Kodagu
- 🍛 Udupi

In the chat input, type any of these:

## Troubleshooting

**Karnataka ideas not showing?**
1. Check server logs for: `✓ Karnataka Districts Integration loaded`
2. Make sure you're using `app_clean.py` (not `app.py`)
3. Try the test file: `test_karnataka_frontend.html`
4. Restart server: Stop and run `python app_clean.py`

**Server not starting?**
```bash
# Check if models are trained
python train_models.py

# Check if data is prepared
python data_preparation.py

# Then start server
python app_clean.py
```
